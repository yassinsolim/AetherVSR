## 4. Clock-Authority Model

Only AudioWorklet `process()` may emit RENDER_TARGET_REACHED after retaining a
contiguous target-crossing block. Main-thread wall time, context polling, rAF and
message arrival cannot do so. Host watchdog and abort flags remain failures even
if a genuine previously queued successful terminal arrives later. A running
AudioContext is recorded state, not evidence of progression.

The prospective dataflow is recorded in ADR-0056. Source pin:
`6e0c4b741c581ac615e8b4675dd723cc729c1a59`. It was committed clean, rebuilt, and
bound to every native artifact. No post-native apparatus repair was made.

## 5. Worklet Completion Design

The target is immutable processor configuration. Short control target equals
epoch+70592; three8192-sample regions start at epoch+12000/+38400/+57600 with
gains1/0.5/0.75 and4800 requested tail samples. A later full-media recording uses
epoch+3216000, with a fixed5s warmup,60s timing window and2s render tail.

State names distinguish RENDER_TARGET_REACHED from WATCHDOG_ABORT,
AUDIO_CONTEXT_SUSPENDED, PROCESSOR_ERROR, DISCONTINUITY, OVERFLOW, HOST_ABORT and
MALFORMED_RESULT. Nonempty PCM alone cannot qualify. Generic manual finish aborts;
terminal buffers/state are single-use and cannot be relabeled by a later command.

## 6. Render-Quantum Semantics

Ranges are half-open[firstFrame,actualObservedEndFrame). The whole last block is
retained, even if it spans requestedEndFrame. Metadata stores both endpoints and
every block length; completion overshoot must be less than that final block's
length. Tests include1/64/96/128/192/256/512-sample blocks. Native observed blocks
were128 samples, not a permanent assumption about WebAudio.

Short-control first1024, requested end71616, actual end71680:64 samples observed
overshoot. Media stopped with DISCONTINUITY, so successful-completion overshoot is
not applicable. The analyzer's negative arithmetic target deficit is not the size
of a discontinuity and is not reported as such.

## 7. Heartbeat

Heartbeats include actual start/end frames, sample rate, block/sample counts,
current block length, state and ordinal. The first block and subsequent progress
of at least12000 frames trigger messages; this is nominal block-rounded4Hz,
not4Hz host delivery. Terminal data replaces a heartbeat due on the last block.

Native short control: six heartbeats; partial media: three. Render endpoint deltas
were12032 frames in both observed streams. Host receive brackets are retained;
no host-delivery-rate or independent timing overhead estimate is inferred.
