## 6. Problem Decomposition

Five independent obligations are source/output readiness, position/size
tethering, fit/crop/mask/clipping, controls/paint order, and ownership/restoration.
Equal outer rectangles cannot establish the other four. ResizeObserver is not
an arbitrary position observer. Filtered bounded MutationObserver does not observe
every layout effect or CSSOM edit. Retained computed-style objects expose current
values when read but provide no notification. Reading live semantic state has a
cost that must be measured; inheriting browser layout does not make renderer work
free. Metrics observe rather than steer any production pipeline.

## 10. Oracle and Boundaries

[Independent oracle](../tools/m108-architecture.mjs) uses current DOM rectangles,
fixture-declared state and direct intersection/fit arithmetic. It neither calls nor
copies inspectGeometry. Candidate full proofs alone reuse the frozen implementation
in an isolated world. The oracle retains the installed canvas across reparenting,
checks exact2x backing, declared fit/masks, original style/parent, pointer behavior
and control hit targets. Maximum placement error0.5 CSS px; recovery deadline500ms
after fixture settling, decoded startup5s. Dummy recovery requires two rAF samples.

Action and rAF observations are same-task sampled states, not atomic physical
presentation. First binding stale observation hides the canvas and trips teardown;
that protection belongs to the sampler, not the candidate. No physical exposure
duration, painted-pixel crop/caption proof or GPU parity is inferred. The control
`submitted` hook executes in a callback finally block, so it is callback completion,
not independently verified successful submission. This limits all control recovery
claims and must be corrected before any future qualification study.

## 11. Observable Support Boundary

The fixed minimum useful support includes moving/resizing video, ABR, equivalent
reparenting, fullscreen, contain/cover, shadow, existing anchors and source overlap.
A post-hoc "static pages only" contract cannot excuse invisible semantic changes.
Configuration-only admission metadata is incomplete; raw prior visible samples
establish admission only for the recorded failures. Unsafe CSSOM transitions lack
reverse recovery; actual crop/caption paint is not tested. These are qualification
gaps, not reasons to erase observed counterexamples. No support predicate qualified.

## 16. Candidate B Ownership

The fixed ownership sequence passed nine cases: absent, empty, noncanonical style,
inline names, stylesheet-important names, escaped names, two videos, forced
collision and exception cleanup. The tenth, host-append, failed. The host added
`--host-added` and color while the lease was active. Release preserved the host
write but left the owned anchor token. Restoring an old whole-style snapshot would
instead clobber current host state. Under the preregistered ownership contract this
lease design is rejected, not optimized after data. Binding suite96/96 NOT RUN.

Independent special review confirmed the rejection. Host replacement/write-away-
back, style-sensitive selectors, live stylesheet names, pseudo-element collisions,
explicit anchor-scope, nested/slotted shadow, video/top-layer fullscreen, dialogs,
popovers and animated/compositor transforms remain NOT PROVED. Nine earlier passes
do not establish universal exact restoration or rule out every future anchor design.

## 23. Preserved Performance Protocol

For a serious survivor: six fresh S1/candidate matched pairs, alternating order,
three repetitions,5s post-readiness warmup then60s stationary playback. Actual
neural throughout, stable owner, zero errors/probes/actual tier changes; same-neural
phase changes recorded. Pointwise one-sided95 bounds use six run-level differences,
sample SD and df5 critical2.0150483733; two-sided critical2.5705818356. No familywise
95% superiority inference. Callback and submission penalty upper95<=0.5fps;
driver-p95 increase upper95<=0.25ms; extra nonnested geometry/presentation JS
upper95<=3ms/s; each guard p95<=0.2ms/max<=2ms; visible fraction>=0.95 including
not-ready. Guard p95>1ms or exact-pair extra JS>15ms/s hard-stops. Missing values
cannot pass. None of these thresholds was exercised or relaxed here.

## 30. Recommended Next Milestone

Recommend a separately authorized bounded design study of an observable semantic
support contract and noninvasive ownership mechanism, before another production
presentation implementation. Correct successful-submission accounting, explicit
admission/rejection predicates, reverse recovery and rendered crop/control proof
before trying to qualify any future survivor. Any new hybrid needs prospective
fixtures, stops and unchanged paired-cost gates; do not tune a rejected candidate
until it passes. No implementation is recommended as already selected. M11,
cross-vendor readiness and broader public acceptance remain gated. Stop here.
