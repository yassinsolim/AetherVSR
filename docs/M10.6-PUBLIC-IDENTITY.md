# M10.6 prospective public-identity correction

This owner-approved amendment supersedes only the cross-session `currentSrc`
digest rule in [the preregistration](M10.6-PREREGISTRATION.md). The original
[metadata pin](../results/m106-public-identity.json) remains unchanged.

The first public ordinal stopped before playback observation or any scheduled
action: its `currentSrc` digest differed from the pin. Two subsequent fresh,
paused metadata-only checks found distinct `blob:` URLs but the same HTTPS HLS
master URL digest and four rendition-path digests. A blob URL is a session-local
MediaSource handle, not a reusable asset identifier. Master manifest body hashes
also differed; signed rendition request query values changed. No playback outcome
was collected in those checks. The original preflight and diagnosis stay local,
with hashes retained in the replacement reference record.

Before restarting ordinal 1, commit the reviewed replacement reference and
apparatus. Compare these observations in all twelve fresh sessions:

- Exactly one observed unsigned HTTPS HLS master URL, with matching origin and
  SHA256 digest. The actual browser response must be HTTP200.
- Exactly the reference set of signed HLS rendition **path** SHA256 digests.
  Query values and CDN hostnames are recorded only as digests/origins and are
  not cross-session identity requirements. No unknown rendition or observer
  overflow may pass; failed manifest responses fail identity qualification.
- Original page origin, blob scheme, metadata dimensions and the already frozen
  duration tolerance. The full blob URL digest remains constant **within** each
  observation; source replacement still fails integrity.

Observe only requests made by the original page. Do not fetch alternative media,
change ABR/source selection, parse or retain public frames, override CORS/EME,
or persist URL paths, signed query values or other media credentials. This test
instrumentation adds no production dependency, permission or source-selection
behavior. The same response observer is present in P/Q/R/S.

These fingerprints identify a stable streaming entry point and observed rendition
paths, not cryptographic equality of every media byte. The original M10.5 asset
had no retained stable master identifier, so a historical asset match remains
unverified. Conclusions concern the freshly pinned public asset and tested browser.

No seek target, clock origin, action, repetition, ordering, stall threshold,
severity/recovery rule or readiness gate changes. Restart the complete fixed
P Q S R / Q R P S / S P R Q sequence; the original failed preflight contributes
no outcome. Primary native-floor data and Case D are unaffected. M10 and M10.5
remain PARTIAL. This is an apparatus correction, not a readiness ADR.
