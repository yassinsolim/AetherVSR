## Metrics and two-trial rule

Record exactly two independent valid final extension Auto trials, in order
final-1 then final-2, each fresh browser/profile,5s warmup after stable neural
readiness then600000ms observation. No selection of the best trial. **Both must
pass every gate below**; any valid failure means performance acceptance FAIL.

- Active runtime delta and wall observation interval both >=600000ms, no rounding.
- Successful submitted frames / wall seconds >=58fps.
- Runtime rVFC-derived presented frames / wall seconds >=58fps.
- `100 * (runtime callback skips + quality dropped delta) / runtime presented delta <=1`.
- The final non-overlapping120s slice has rendered AND presented rate >=58fps.
- No controller tier change/fallback, non-neural submitted frame, owner change,
  runtime error, integrity event or application submission deficit.

Report quality-drop percentage separately (quality dropped / quality total),
native callback-gap percentage (gap / native presented delta), actual application
attempt minus submission deficit, and rendered-vs-presented deficit. Missing or
reset counters stay unavailable; an unavailable acceptance operand cannot pass.
GPU quantiles use available submitted-in-window raw samples, with counts; they
are not a substitute for delivery acceptance. First and last120s remain visible.

## Invalidity and retention

External blur/hidden/pagehide, user pause/play/source/rate changes, changed native
window/display, recorder overflow/missing counts or changed source/bundle invalidate
a capture. Abort and retain its raw/hash/reason. Runtime/device errors, unexpected
owner changes or application submission failures are binding failures, not retriable
external interruptions; preserve them and run the next ordinal if practical. Do not
force focus or splice pre/post interruption. Only invalid captures may be retried,
with a new name and the same trial ordinal before later unrun trials. A valid
low-FPS/high-loss result is NOT retryable. Final-2 runs even if final-1 fails loss.

Prior M9/M10 worktree and repeated matched-page studies are controls, not final
trials. Independent reviewers check all final rows/last windows, no favorable
selection, denominator fidelity, parity, lifecycle and the final verdict.

public compatibility are independent gates. UI reload is the tested development

public breadth is required; current Shaka and Video.js successes do not excuse loss.
