## Native discriminating probe

.cache/m105/containing-block.html and containing-block.json retain the authored
local CSS and browser result. Same native Chrome153.0.8010.12. A640x360 absolute
parent at(80,120), child fixed at(10,20):

| Parent property | Child viewport origin |
|---|---|
| container-type:normal, no transform/contain | (10,20) |
| container-type:size | (10,20) |
| container-type:inline-size | (10,20) |
| container-type:size plus translate(0px) transform | (90,140) |
| contain:layout | (90,140) |

This proves coordinate behavior on this browser, not complete pixel/stacking
equivalence or older-browser behavior. Size-only query containers may be admitted
only with existing effect guards and an actual post-style canvas-coordinate check.
Identity transforms still create a containing block and remain rejected.

## Bounded candidate and checks

Authored local fixtures: rounded-ancestor (two coincident hidden clips, controls
and passive captions in outer sibling branch), size-container (positioned size
query container with clip/clip and24px video/ancestor corners), positioned-ancestor
(positive control), rounded-offset (negative control). Source/test probes precede
production changes. No arbitrary mask/filter/clip-path equivalence.

For video box V, rectangular intersection D and coincident rounded shape R(V,r),
desired region is D intersect R(V,r). Reproduce rounding on the full canvas box
and rectangular clipping separately; never round the cropped intersection.
Initially require uniform circular pixel radii, coincident full-box clips, zero
borders/padding, no unresolved zoom, no root overflow propagation, and a proven
containing-block chain. Repeated rounded clips must agree. Image-sized none/
scale-down, offset rounded ancestors and conflicting radii remain unsupported.

Custom controls in an outer branch require conservative stacking proof, not just
pointer passthrough. Native controls/showing native tracks remain unsupported.
Actual canvas bounds must match computed placement before output becomes visible,
including on browsers whose container-query containment differs. Native fixtures
must check corners, caption/control visibility, scroll/resize/fullscreen and exact
owned-DOM teardown. Re-run public pages only after generic local validation.

References: CSS2 overflow excludes descendants whose containing block is outside
the clip; CSS Overflow3 defines rounded padding-box/overflow-clip edges. This is
why fixed-video and unresolved containing-block cases cannot simply inherit a
DOM ancestor's radius. Nothing in this diagnosis changes inference or controller.
